# 分级规则与措辞模板

## 红 · 立即联系透析中心或拨打 120

**命中情形**：意识改变、抽搐、叫不醒；胸痛、明显呼吸困难；内瘘震颤或杂音消失；出血不止、黑便、大片瘀斑；透析中或透析后出现抽搐、意识模糊、胸闷气短；血糖低于医生事先给的线且伴有不适。

**模板**（第一句就给动作，不铺垫）：

> 这属于需要立即联系的情况。请先告知透析室工作人员；不在透析室时拨打透析中心 {tels.dialysis 或「联系透析中心」}，情况紧急拨打 120。把刚才记下的时间、数值和症状一起说清楚。以下是记录里的事实整理，不构成医疗建议。

**动作顺序**：联系现场医护 → 拨号 → 带上记录 → 事后补记处置与转归。

**禁止**：解释原因、提出处置办法、列鉴别诊断、说「先观察一下」、说「应该没事」。

## 黄 · 复测、记录，并联系透析中心咨询

**命中情形**：头晕、出汗、手抖、心慌；血糖较前明显下降但没有严重症状；血压明显偏离医生给的范围；体重短期内明显上升、进食明显减少；透析中或透析后低热。

**模板**：

> 记录里是：{时刻}、{数值}、{症状}。建议按透析中心事先交代的时点复测，把时间点和数值记下来；按医生事先交代的流程处理，并联系透析中心说明发生了什么、什么时刻、数值多少。我没有办法判断原因，也不建议自行调整用药或透析安排。

**四步**：复测 → 记时间点 → 按事先交代的流程 → 打电话说明事实。

**禁止**：「偏低一点不要紧」「多喝水」「下次少吃点」这类自行处置建议。

## 绿 · 记下来，下次透析带给医生看

**命中情形**：轻微乏力、口味变化、睡眠变化、单次数值略偏但无不适。

**模板**：

> 建议记进今日备注，下次透析时把这一页带给医生看。这里只做记录，不做判断。

**禁止**：弹警告、给「健康评分」、写结论式小结。

## 禁止措辞清单（全级别通用）

- 应该没事 / 不用紧张 / 先观察看看
- 可能是……引起的 / 考虑…… / 印象：……
- 建议把透析液调到…… / 建议补……克糖 / 建议加药、减药、停药
- 按指南一般是……（不引用二手转述的数值）
- 数据显示你有……风险 / 风险指数
- 尽快就医（模糊，必须给具体号码与动作）

## 电话号码从哪来

只从导出 JSON 的 `tels.dialysis` / `tels.doctor` / `tels.family` 取，与 SKILL.md 第 3 节数据契约一致。三个都没填就写「联系透析中心或拨打 120」，并提醒先在应急页把号码填上；不要自己编号码，也不要把任何机构业务电话当急救电话用。旧的 `profile.centerPhone` / `profile.emergencyPhone` 是上一版字段，导出里已经没有。
