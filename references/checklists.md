# 分级排查、常见情况速查与数据字典

从工具包知识页搬过来的结构化内容，用来对齐导出备份里的字段与标签。解读记录时以 SKILL.md 第 3 节数据契约为准，本文件只提供标签全集。

## 一、红 / 黄 / 绿三级排查

### 红 · 立即联系透析中心或拨打 120

- **命中情形**：意识改变、抽搐、叫不醒；胸痛、明显呼吸困难；内瘘震颤或杂音消失；出血不止、黑便、大片瘀斑；透析中或透析后出现抽搐、意识模糊、胸闷气短；血糖低于医生事先给的线且伴有不适
- **动作**：先联系现场医护或拨号 → 把刚才记下的时刻、数值、症状一起说清楚 → 处置与转归事后补记。页面不解释原因、不给药。
- **联系**：立即拨打

### 黄 · 复测、记录，并联系透析中心咨询

- **命中情形**：透析中或透析后头晕、出汗、手抖、心慌；血糖较前明显下降但没有严重症状；血压明显偏离医生给的范围；体重短期内明显上升、进食明显减少；透析中或透析后低热
- **动作**：按医生事先给的时点复测 → 记下时间点与数值 → 按医生事先交代的流程处理 → 打电话说明发生了什么、什么时刻、数值多少。
- **联系**：联系透析中心

### 绿 · 记下来，下次透析带给医生看

- **命中情形**：轻微乏力、口味变化、睡眠变化；单次数值略偏但没有不适
- **动作**：建议记入今日备注，不弹警告、不做判断。
- **联系**：记录即可

完整措辞模板与禁止措辞见 `triage.md`。

## 二、常见情况速查 · 5 条

| 看到什么 | 先记什么 / 做什么 | 联系谁 |
| --- | --- | --- |
| 透析后期头晕、出汗、手抖、胸闷 | 立即测血糖，一键标记症状（自动带上已透析分钟 / 剩余分钟）；按医生事先给的处置流程处理；复测后记数值与转归 | 症状出现即告知透析室工作人员；反复出现则复诊时带上时序记录 |
| 内瘘震颤变弱或摸不到 | 不要按压、不要自行处理，记录发现时间 | 立即联系透析中心 |
| 皮肤瘀斑、牙龈出血、黑便 | 记录部位与时间，带上最近一次血常规结果 | 立即联系医生 |
| 体重短期内明显上升 | 回看饮水与饮食记录，核对透前体重 | 下次透析前告知透析室，不自行调整饮水或用药 |
| 透析后发热 | 记体温与时间点，看是否伴寒战 | 体温持续或伴寒战，联系透析中心 |

表里写的是「先做什么、联系谁」，不是诊断，也不是处置方案。命中红级情形一律跳过表格，直接按 SKILL.md 第 2 节给拨号三步。

## 三、导出数据字典

解读 JSON 备份里的 `symptoms[]` / `gluAt` 等字段时按下面的标签对齐，别自己造词、别把没记录的字段补成 0。

### 症状标签 `symptoms[]`

出汗、手抖、心慌、头晕、胸闷、气短、抽搐、意识模糊、乏力、其他

### 化验项目名 `labNames`

血红蛋白、血小板、钾、磷、钙、PTH、血糖、HbA1c、白蛋白、肌酐

> 工具当前版本没有化验模块，导出里没有 `labs` 字段。这份项目名只是标签全集，不要据此编造化验数值或解读化验单。

### 每日记录字段 `dailyTypes`

| 字段 | 名称 | 单位 |
| --- | --- | --- |
| `weight` | 体重 | kg |
| `glucose` | 血糖 | mmol/L |
| `sbp` | 收缩压 | mmHg |
| `dbp` | 舒张压 | mmHg |
| `hr` | 心率 | 次/分 |
| `temp` | 体温 | ℃ |
| `water` | 饮水 | mL |
| `urine` | 尿量 | mL |
| `meal` | 进食 / 加餐 | — |
| `symptom` | 症状 | — |
| `note` | 备注 | — |

### 血糖时点 `glucoseTags`

透析前、透析中、透析后、加餐后、空腹、睡前、其他

`gluAt` 的取值来自这里；没填时点就写「未填时点」，不要按日期猜。
